# Visuals Overlay v5 (OpenGL, Minecraft Java)

Косметический оверлей в виде DLL для Minecraft Java Edition (Windows x64): профессиональный прицел,
эффекты клика, HUD в стиле клиентов, атмосферные эффекты и анимированное меню на ImGui.

Minecraft Java рисует через **OpenGL**, поэтому DLL хукает `gdi32!SwapBuffers`.

## Возможности

**Экран функций (как в PulseVisuals)**
- Вкладка «Функции» — сетка всех 21 модуля оверлея в две колонки.
- Категории: Все / Visuals / HUD / Utilities со счётчиками и фильтром в один клик.
- Карточка модуля: имя, описание, индикатор состояния и мини-переключатель.
- Клик по карточке включает функцию; счётчик «N / 21 активно» показывает сводку.

**Прицел (12 стилей, меняется на лету)**
- Крест, круг, точка, T, X, квадрат, стрелки, ромб, кольцо, тактический, скобки, звезда.
- 8 готовых пресетов: Классика, PvP, Минимал, Неон, Тактикал, Кибер, Стрелки, Звезда.
- Размер, зазор, толщина, точка, прозрачность, обводка, вращение, свечение.
- Радужный режим и привязка к акцентному цвету.
- Реакция на клик: прицел расширяется и плавно возвращается.
- Живой предпросмотр в меню (ЛКМ по нему — тест анимации).
- Быстрая смена стиля клавишей (по умолчанию `F6`).
- Отдельная настройка «скрывать в меню».

**Эффекты клика**
- Частицы (круги / искры / смешанный режим), количество, скорость, гравитация, размер.
- Ударная волна, вспышка краёв экрана.
- Плавающая пыль в воздухе, след курсора в меню.

**Экран**
- Виньетка, свечение краёв, цветовой фильтр, мягкое свечение центра (bloom), затемнение меню.

**HUD**
- Ватермарк с градиентом, FPS, часами и датой; масштаб и позиция.
- График FPS с заливкой.
- Клавиши W/A/S/D, ЛКМ/ПКМ, SPACE, SHIFT/CTRL с CPS и анимацией нажатия.
- Список включённых модулей (ArrayList) в стиле клиентов.
- Uptime сессии и потребление RAM процесса.
- Всплывающие уведомления.

**Меню и конфиг**
- Тёмное анимированное меню с карточками, акцентом, свечением и кастомными виджетами.
- 6 тем акцента + радужный режим, настройка скругления, прозрачности и анимации.
- 3 профиля конфигурации + автосохранение.
- Горячие клавиши: меню, вкл/выкл оверлей, смена прицела, паника.
- «Скрывать вне игры»: в главном меню, паузе и инвентаре Minecraft HUD, прицел и эффекты
  не рисуются — оверлей остаётся доступен только в мире (настройка в «Конфиг» и «Функции»).

## Горячие клавиши по умолчанию

| Клавиша | Действие |
|---|---|
| `INSERT` | открыть/закрыть меню |
| `RIGHT SHIFT` | включить/выключить оверлей |
| `F6` | следующий стиль прицела |
| `DELETE` | паника (скрыть оверлей) |
| `1`–`7` | переключение вкладок меню |
| `Esc` | закрыть меню |

Все клавиши меняются во вкладке **Конфиг → Клавиши**.

## Сборка на GitHub (без Visual Studio)

В репозитории лежат только исходники — пять файлов, никаких библиотек и папки `build`:

```
CMakeLists.txt
README.md
.gitignore
src/visuals_overlay.cpp
.github/workflows/build.yml
```

1. Создайте на GitHub пустой репозиторий (без README и .gitignore).
2. На странице репозитория: **Add file → Upload files**. Откройте папку `visuals-overlay-github`
   и перетащите в браузер все 5 элементов сразу: `CMakeLists.txt`, `README.md`, `.gitignore`,
   папки `src` и `.github`. Нажмите **Commit changes**.
   Лимит GitHub «не больше 100 файлов за раз» при этом не затрагивается: папку `build`
   и скачанные ImGui/MinHook загружать не нужно, CI скачает их сам.
3. Откройте вкладку **Actions** → workflow **Build DLL** (запускается сам после коммита).
   Если он не стартовал, нажмите **Run workflow**.
4. Через 2–4 минуты откройте успешный запуск → блок **Artifacts** → скачайте
   `visuals-dll.zip`, внутри `visuals.dll`.

Тег вида `v5.0` дополнительно публикует готовый DLL в **Releases** репозитория.

Локальная сборка (если установлен CMake + Visual Studio):
`cmake -S . -B build -A x64` и `cmake --build build --config Release`.
Сборка использует статическую CRT, поэтому DLL не требует установленного VC++ Redistributable.

## Как загрузить

1. Через лаунчер: `System.load("путь\\visuals.dll")` (вызовется `JNI_OnLoad`) или JVM-аргумент
   `-agentpath:путь\visuals.dll` (`Agent_OnLoad`).
2. Обычный `LoadLibrary` в процесс игры (`DllMain`).

Конфиг `visuals.cfg` (и `visuals_1..3.cfg` для профилей) сохраняется рядом с DLL.

## Ограничение

Оверлей рисует поверх кадра и не видит данные игры (урон, здоровье, FOV). Хитмаркеры по урону,
полосы HP и зум требуют интеграции в саму игру, например мода Fabric. Реакция прицела привязана
к клику мыши, а не к попаданию. Ванильный прицел Minecraft остаётся под оверлеем — убрать его можно
только модом или ресурспаком.
